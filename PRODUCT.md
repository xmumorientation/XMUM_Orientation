# Product

## Register

product

## Users

XMUM Orientation 2026 freshies, facilitators, game masters, guardian game masters, committee members, HOF/HOGM, and admins. They use the app on phones during a live campus event, often while moving, handling queues, checking group status, or resolving game operations under time pressure.

## Product Purpose

XMUM Orientation Platform unifies event access, role-based workflows, attendance, location reporting, token transactions, inventory, gacha, puzzle verification, NFC projector activation, and live operations control. Success means staff can run the event without paper drift, groups can see their progress clearly, and admins can control game phases and emergency switches without redeploying.

## Brand Personality

Playful, clear, operational. The 2026 theme is "Vortexa", but the interface must still behave like a trusted event control surface.

## Anti-references

Avoid generic purple-gradient SaaS dashboards, over-decorated glass cards, tiny low-contrast labels, emoji-only affordances, and marketing-page drama inside task workflows. The app should not feel like a brochure once the user is signed in.

## Design Principles

1. Make the next action obvious within one glance.
2. Keep event-critical controls high contrast and thumb friendly.
3. Let role and phase context shape navigation instead of showing everything.
4. Use the Vortexa theme as identity, not decoration.
5. Prefer trustworthy product patterns over novelty.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Maintain 44px minimum touch targets, visible focus states, readable 16px mobile body text, reduced-motion fallbacks for decorative animation, and status indicators that do not rely on color alone.
